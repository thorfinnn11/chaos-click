## 🎯 The Premise

At **Stage 0**, Halcyon is completely sincere: a believable, polished SaaS product website that could plausibly be pitched to modern remote organizations. It offers "focus and wellbeing analytics", gentle check-ins, team activity feeds, and a $6/user pricing tier.

As the user clicks the primary action button ("Start free trial"), each interaction does not open a signup modal, but instead triggers a steady, calculated descent through 6 stages of behavioral decay into a full Orwellian surveillance apparatus (Ministry of Truth / Telescreen terminal).

The humor and tension rely entirely on the initial authenticity—there are no jokes, no visual glitches, and no hints of surveillance at Stage 0.

## ⚡ The 6-Click Escalation Protocol

Every click increments the internal `clicks` counter and calculates the chaos metric (`chaos = Math.min(100, Math.round(nextClickCount * (100 / 6)))`).

```
Click 0 (0% Chaos)   ──► Sincere SaaS ("Start free trial")
Click 1 (17% Chaos)  ──► Subtle Suffixes ("Continue")
Click 2 (33% Chaos)  ──► Presence Verification ("Proceed to step 2") [Filler Step]
Click 3 (50% Chaos)  ──► Telemetry Mandate ("Acknowledge") + Cookie Banner
Click 4 (67% Chaos)  ──► The Mask Slips ("Comply") + Button Evasion
Click 5 (83% Chaos)  ──► Brutalist Instrument Panel ("SUBMIT COMPLIANCE")
Click 6 (100% Chaos) ──► Meltdown & CRT Collapse ("Audit complete. You were never alone.")
```

### Detailed Stage Breakdown

1. **Click 0 / Step 0: "Pristine Halcyon" (0% Chaos)**
   - **Headline:** *"Help your team find its focus."*
   - **CTA Button:** `"Start free trial"` (graphite pill button with amber glow)
   - **Activity Feed:** *"Priya started a focus block"*, *"Meeting-free Wednesday is on"*.
   - **Meter:** 20-segment "Focus score" bar sitting at baseline health.
   - **Visuals:** CRT effects, grain, and scanlines dialed to imperceptible opacity (`0.03`).

2. **Click 1 / Step 1: "Something's Off" (~17% Chaos)**
   - **Headline:** *"Help your team stay focused."*
   - **CTA Button:** `"Continue"`
   - **Activity Feed:** Lines gain unsettling suffixes: *"Priya started a focus block. You were notified."*
   - **Visuals:** Scanlines and film grain subtly increase; audio triggers a deeper mechanical click tone.

3. **Click 2 / Step 2: "Presence Verification" (~33% Chaos) — *Filler Step***
   - **Headline:** *"Monitor where your team's attention goes."*
   - **CTA Button:** `"Proceed to step 2"`
   - **Activity Feed:** Idle latency tracking active; prompts check latency every 8 minutes.
   - **Feature Cards:** Feature cards shift to *Focus metrics*, *Passive check-ins*, *Team reporting*.

4. **Click 3 / Step 3: "Warm & Uncomfortable" (~50% Chaos)**
   - **Headline:** *"Know where your team's attention goes."*
   - **CTA Button:** `"Acknowledge"`
   - **Feature Cards:** *"Required check-ins"* (mandatory biometric checks), *"Attributed and archived"* (keystroke dossiers).
   - **Banner:** Fixed bottom compliance banner slides up with a non-dismissible single `"Acknowledge & Comply"` action.
   - **Visuals:** Headline begins subtle RGB chromatic aberration slice; panels gain a 0.5° tilt.

5. **Click 4 / Step 4: "The Mask Slips" (~67% Chaos)**
   - **Headline:** *"Attention is a resource. We allocate it."*
   - **CTA Button:** `"Comply"` — **Button actively evades and runs away from the user's cursor** when hovered.
   - **Feature Cards:** *"Assigned time"*, *"Interviews"*, *"Dossiers"*.
   - **Testimonial:** *"I have never felt so observed. I mean supported."* — Subject 418.
   - **Visuals:** Layout shakes on each click; random horizontal difference-blend tear bars appear; click debris starts scattering across screen coordinates.

6. **Click 5 / Step 5: "Brutalist Collapse" (~83% Chaos)**
   - **Layout:** Complete transformation into the 3-column brutalist instrument panel from `chaos-click.html`:
     - **Top Bar:** Terminal ID `HALCYON // AUDIT_TERMINAL_0451` on the left, live uptime clock on the right (`00:MM:SS`).
     - **Left Column:** Sharp-bordered *Operator Log* with newest lines on top, dashed dividers, and auto-scrolling terminal commands.
     - **Center Column:** Massive Anton font title:
       ```
       WE ARE WATCHING.
       YOU ARE FOCUSED.
       ```
       Below it: a large physical round arcade key button with graphite ring, radial gradient, and stepped hard drop shadow (`7px 7px 0 #0a0a0a`).
     - **Right Column:** *Entropy Panel* featuring the 20-segment vertical LED meter with live numeric readouts for inputs, chaos %, and state.
     - **Bottom Bar:** Endless scrolling ticker footer with accelerated marquee speed.
   - **Visuals:** Ghost cursor ring lagging behind mouse pointer, ambient film grain, CRT scanlines, flicker, and chromatic split glitch copies.

7. **Click 6 / Step 6: "Meltdown / Room 101 Audit" (100% Chaos)**
   - **CRT Power-Off Animation:** Entire interface collapses vertically to a razor-thin blinding amber beam (`scaleY(0.002)`), spikes in brightness, and fades out.
   - **Error Screen Modal:** Pitch-black audit interface with Anton condensed headline:
     ```
     AUDIT COMPLETE.
     YOU WERE NEVER ALONE.
     ```
   - **Diagnostics:** Full click APM, highest chaos recorded, and surveillance notes.
   - **Recovery:** Clicking `"Return to your desk"` triggers a reverse CRT power-on transition, wiping thoughtcrime logs and cleanly restoring pristine Stage 0 Halcyon.

## 🛡️ Architecture & Hard Rules Compliance

The visual re-skin strictly follows the architectural separation rules:

1. **Zero Logic Mutation:** All existing application logic, state hooks (`chaos`, `clicks`, `logs`), audio engine synthesizers, and event handlers remain identical in structure and behavior.
2. **Read-Only Visual Layer:**
   - `src/components/VisualVintageLayers.tsx` houses canvas film grain, CRT scanlines, horizontal tear bars, ghost cursor, and click debris. It is marked `/* VISUAL LAYER ONLY */` and exclusively reads `chaos` and click events without modifying state.
   - Text transitions are handled by `src/utils/useScramble.ts`, which performs quick character scrambles (~300ms, `ease-io`) during step updates without altering underlying data.
3. **Accessibility:**
   - Full keyboard focus outlines (`outline: 2px solid var(--accent)`).
   - `@media (prefers-reduced-motion: reduce)` disables continuous screen tears, high-frequency shakes, and rapid flickers.

## 🕹️ Controls & Easter Eggs

- **Main Clicker:** Click the primary action button to advance the chaos meter.
- **The Brotherhood Cipher (Konami Code):**
  Enter `↑ ↑ ↓ ↓ ← → ← → B A` on your keyboard to instantly trigger the Emmanuel Goldstein takeover manifesto and trigger maximum chaos.
- **Terminal Commands:**
  Type commands into the left Operator Log input:
  - `help` — List available operator diagnostics
  - `audit` — Run immediate telemetry diagnostic
  - `status` — View current thoughtcrime level
  - `clear` — Flush the current log feed
- **Tab Inactivity Detection:**
  Switch away from the browser tab to watch the document title shift to alert status: *"👁️ BIG BROTHER SEES YOU AWAY"*.
- **Idle Recovery:**
  Prolonged inactivity gently cools down chaos if below 100%, accompanied by telescreen reminder prompts.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone <repo-url>
cd Halcyon-Chaos-Click

# Install dependencies
npm install

# Start the local development server (runs on port 3000)
npm run dev
```

### Production Build
```bash
# Compile and package for production
npm run build
```
